# Tiara

A combined, cross-platform frontend for my [Gown](https://gitlab.com/lfknudsen/gown), [Mark](https://gitlab.com/lfknudsen/mark),
and [Plume](https://gitlab.com/lfknudsen/plume) servers.

More or less feature complete, but I don't know Flutter well enough to give proper setup/use instructions,
and it has not been tested on any platform other than Windows native.
